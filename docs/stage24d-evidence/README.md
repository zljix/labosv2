# Dokazi etape 24D

`functional.tap` i `sensor-results.json` nastaju izvršavanjem funkcionalnog skupa. Rezultati uključuju točan hash snimke i ugovora, cilj, privatnu pobudu pokusa, provenijenciju artefakta, kriterije i opažanja. CI istim skupom uključuje neovisne S3 i AVR prijevode kada su postavljeni odgovarajući alati.

`mysql-sensors.json` nastaje samo u stvarnoj PHP/MySQL integraciji. Povezuje nove objavljene rubrike, revizije, poslove, bodove i zaključavanje te provjerava očuvanje ranije predaje.

Lokalni preskočeni prevoditeljski ili MySQL test nije uspješan dokaz tog puta. Objavu treba povezati s uspješnim CI izvođenjem iste izvorne snimke. Stvarni učenički pilot i ciljna školska računala ne potvrđuju se razvojnim skupom.
