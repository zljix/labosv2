# Dokazi etape 24G

Izvršni zapisi pripadaju označenom izvoru i okruženju. `steppers-<target>.json` bilježi stvarni rezultat svake provjere, hash snimke, ugovor i izvorni commit; `mysql-steppers.json` bilježi PHP/MySQL dodjele, bodove i zaključavanje. `ci-native-summary.json` provjerava sva četiri cilja i 36 neovisnih C++ prijevoda. Preskočeni test ne znači izvršen prijevod. Lokalno izvođenje poznatih referenci služi razvoju i nije dokaz Linux izolacije.
