# Izvršni dokazi 24I

[Završni prihvat](https://github.com/zljix/labosv2/actions/runs/43949417346) potvrđuje osam službenih dodjela, cijela OLED brojčana polja, dva vala po 30 sintetičkih predaja, atomsko ponavljanje SQL transakcije, izvještaje, povrat kopije i paket. `acceptance-summary.json` povezuje otiske izvora i instaliranog provjeravača.

`native/` sadrži četiri izvorna izvršna dokaza i 24 neovisna C++ prijevoda. `boundary-validation.json` zasebno opisuje konačnu provjeru brojčanih granica i DB doradu; prevoditelji, runtimeovi, driveri i rubrike ostaju isti. `mysql-environment.json` i `load-first.json` / `load-second.json` nastali su s konačnim izvorom. Detaljni sintetski radovi čuvaju se u artefaktima prihvata i školskom paketu.
