# Završni dokazi etape 24J

[Potpuni prihvat](https://github.com/zljix/labosv2/actions/runs/43959526722) povezuje 234 ciljane izvedbe, 72 neovisna C++ prijevoda i 24 stvarne PHP/MySQL dodjele s istim bajtovima provjeravača. Sva četiri cilja imaju tri ponavljanja svih šest referentnih programa; alternativni izvori, prekidi i oba pogrešna funkcionalna kriterija imaju zasebne dokaze.

`acceptance-summary.json` sažima potvrđeni opseg. `program-provenance.json` dokazuje da se školski i nativni prihvat razlikuju samo dodatnim workflowom; SHA-256 provjeravača je jednak. Detaljni sintetski zapisi nalaze se u CI artefaktima i potpunom školskom paketu. Stvarni školski pilot ostaje zasebna provjera.
