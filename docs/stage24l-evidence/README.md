# Dokazi etape 24L

Izvršne provjere bilježe cilj, ugovor, snimku i stvarni rezultat u optical-*.json. PHP/MySQL prihvat bilježi 16 zaključanih dodjela i čuvanje ranijih bodova. Prihvat sadrži tri ponavljanja, prekide i popravak, drugo sjeme, alternativne algoritme te neovisno pogrešne osnovne i napredne kriterije.
