# Dokazi etape 24N

`levels-<cilj>.json` čuva izvođenja spremljenih programa, točne snimke, sjeme, bodove i otiske. `ci-native-summary.json` potvrđuje ponovljivost četiriju referenci po cilju i 48 neovisnih C++ prijevoda. `mysql-levels.json` povezuje 16 zaključanih dodjela sa stvarnim PHP/MySQL ugovorima i očuvanom ranijom predajom. `acceptance-summary.json` nastaje tek nakon uspješnog završnog prihvata i usporedbe otiska provjeravača.

Detaljni izvedeni dokazi isporučuju se u CI artefaktima i školskom instalacijskom paketu. Kratki sažetak, podrijetlo paketa i zapis javne objave dodaju se nakon provjere. Ovdje nema stvarnih učeničkih podataka.
