LABOS / ISTRAŽIVAČKI PROTOTIP 03

Arduino, bez mreže.

Pripremi prevoditelj jednom. Promijeni program offline, prevedi ga i provjeri u Labosovu AVR simulatoru.

1. Priprema preglednika

Provjeravam spremljeni paket…

Uno / klasični Nano · ATmega328P · eksperimentalni GCC 15.2 · Arduino jezgra 1.8.8. Podržani su main.ino i zasebne C/C++ datoteke; funkcije deklariraj prije poziva. Wire, SPI i EEPROM dio su paketa. Dodatne biblioteke odaberi ispod. ESP32-S3 još nije podržan.

Projekt iz Labosa

Projekt JSON čuva izvor, sklop i bilješke za povratak u Labos. Rezultat prototipa otvara se ovdje. Odaberi 1,2, 3 ili 5 s simuliranog vremena (DHT22 treba barem 3 s); nema upravljanja ulazima sklopa tijekom izvođenja.

Sklop još nije pokrenut.

2. Napiši program

Biblioteke programa

Koriste se iste zaključane inačice kao u Labosu. DallasTemperature uključuje OneWire; odabir jednog U8g2 paketa zamjenjuje drugi. Promjena izbora zahtijeva novo prevođenje.

Program još nije preveden.
